HOW TO MODIFY THE FONT 
There's a JSON file in the folder and a glyphs.png
1. Go to https://yal.cc/tools/pixel-font/
2. Top-Left -> Menu -> Import Settings -> Add the .json file. 
3. Pick image -> glyphs.png 
Now you can see the font's skeleton and how it was made. You can mess around with the values to see what they do. 
If you want to add new letters or symbols, just draw something new in glyphs.png, then add the letter in the site as well, in the "Glyphs in image:" box. 
For more info I recommend searching in youtube "Make a Pixel Art Font - Beginner Tutorial", it shows you how to use the site.

The license for the font is that you can do whatever you want, including commercial projects, no credit desired, just don't sell the actual font itself. 

Note: you might have noticed in glyphs.png that there's a "square" symbol there, second row, 6th box after "?" and before "0". It's a placeholder for "space" as in " ". Anything drawn in the "space" box is ignored by the site so you won't actually see a square drawn, but just keeping an empty box was confusing.
